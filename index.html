THINGS I'VE BUILT

start to finish, every layer.

  • Voice CRM Agent

    IN PROGRESS · AGENTS

    An agent that listens to live customer calls, transcribes them as they happen and pulls out the lead: name, contact details, what they want. The hard part is judgement, so it spots duplicates and unclear calls and decides when to file a lead itself and when to hand it to a person.

    python · node · openai / claude · speech-to-text · postgres

  • AccidentAI

    PROJECT · DEEP LEARNING

    Pick any route and see where accidents are likely, drawn as a heatmap. A hybrid CNN, BiLSTM and GRU model trained on the US Accidents dataset, with SMOTE rebalancing and per-class thresholds so the rare, severe crashes don't get lost. Live weather from Open-Meteo, routes from OSRM.

    python · tensorflow / keras · flask · leaflet.js · osrm · openstreetmap

  • AI Helpdesk

    PROJECT · FULL STACK

    A ticketing platform where an LLM classifies every new ticket, works out the intent and suggests a first reply, so agents skip most of the triage. Admin, agent and customer roles, SLA tracking, audit logs and real-time dashboards, shipped through CI/CD.

    react · typescript · node · postgres · rest apis · llms
